# 디자이너 원본 아이콘

이 폴더에 첨부했던 PNG 원본을 아래 이름으로 넣으면 다음 앱 빌드에 자동으로 포함됩니다.
별도의 Kotlin 수정은 필요 없습니다. 파일명은 소문자이며 정확히 일치해야 합니다.

| 파일명 | 사용 위치 | 원본 기준 크기 |
| --- | --- | --- |
| logo.png | 스플래시 중앙, 홈·테마 상단 로고 | 100×100 |
| arrow_right.png | 대화 시작하기 우측 화살표 | 40×40 |
| steering_wheel.png | 참여자 선택의 운전석 표시 | 약 39×39 |
| chevron_right.png | 전체 테마 우측 꺾쇠 | 약 13×24 |
| restart.png | 완료 화면의 같은 테마 재시작 | 약 40×40 |

원본의 투명 배경과 여백을 유지하세요. 가로세로 비율을 보존하여 표시하며 임의 색상은 입히지 않습니다.
예외적으로 흰색 운전석 아이콘은 선택되지 않았을 때만 회색으로 표시합니다.

PNG 원본 5개가 프로젝트에 추가되어 앱에서 사용합니다. 파일이 없는 경우에만 기존 Canvas 도형을 표시합니다.

화살표 파일의 투명 여백을 포함한 정사각형 캔버스를 유지합니다.
대화 시작 화살표는 56×56, 전체 테마 꺾쇠는 48×48 영역에 배치합니다.
꺾쇠를 좁은 13×24 영역에 넣어 원본의 여백까지 과도하게 축소하던 문제를 수정했습니다.

## 현재 화면 색상
사용자 요청으로 카테고리별 팔레트 적용을 취소하고 이전 시안 색상으로 복원했습니다.
- 배경: #F6F7F9
- 대화 시작/탭 강조: #6041FF
- 스몰 토크: #53D1B1
- 유머러스/밸런스 게임: #4D94FF
- 로맨틱/이심전심: #E568BB
- 오늘의 이야기/여행의 순간: #FF795A
