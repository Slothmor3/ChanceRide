# app

어쩌다 동승의 실행 모듈입니다.

- `MainActivity`: 스플래시, 홈, 테마 탐색, 상세, 참여자 설정
- `PlayActivity`: 음성 플레이와 완료 화면
- `RideApplication`: 앱 범위의 세션 저장소
- `data/SessionStore`: 버전이 있는 로컬 저장 형식과 유효성 검사
- `ui/`: 시안 레이아웃, 공통 스타일, 원본 아이콘 및 대체 도형

실행 방법과 기능 소개는 [루트 README](../README.md),
SDK와 상태 전이는 [아키텍처](../docs/ARCHITECTURE.md),
테스트 명령은 [검증 문서](../docs/TESTING.md)를 참고하세요.
